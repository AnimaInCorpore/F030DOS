# Falcon3 DOS oracle

Status: `IDENTIFIED` for the Instant Action startup path; campaign and Red
Flag memory requirements remain `TBD`.

## Image and DOS configuration

The bootable image is generated by `work/build_dos_hdd.py` from the extracted
Falcon3 tree and genuine MS-DOS 6.22 installation floppies. The floppy source
used for this run was supplied from the sibling project:

```text
C:\Arbeit\F030TieFighter\img\Microsoft MS-DOS 6.22 Plus Enhanced Tools (3.5)
```

The builder performs a two-stage boot. First, a plain DOS configuration runs
the genuine `EXPAND.EXE` over the KWAJ-compressed DOS drivers. It then rewrites
the image to this runtime configuration:

```text
DEVICE=C:\DOS\HIMEM.SYS
DOS=HIGH
FILES=20
BUFFERS=15
```

`AUTOEXEC.BAT` changes to `C:\FALCON3\FALCON3.EXE` after the bootstrap. The
final image is 64 MiB, contains 697 game files, and boots from the genuine
MS-DOS 6.22 boot record with the project MBR/geometry checks enabled.

## Observed startup sequence

With `python work/run_qemu.py --timeout 60 --shot 20`, QEMU reaches the DOS
prompt and launches Falcon3 without the earlier conventional-memory failure.
The timed interaction below reproduces the next transition:

```text
python work/run_qemu.py --timeout 60 --key 20:spc --key 30:spc \
  --key 36:right --key 37:right --key 38:right --key 39:right \
  --key 40:up --key 41:up --key 42:up --key 43:up --key 45:ret \
  --shot 34 --shot 43 --shot 49 --shot 55
```

The observed states are:

1. Spectrum HoloByte splash and Falcon3 title/credits.
2. War Room with no squadron or theater selected.
3. Four right-arrow and four up-arrow events move the keyboard cursor to the
   upper-right `INSTANT ACTION` monitor.
4. Enter activates the monitor.
5. Falcon3 reaches the F-16 cockpit in flight, showing the HUD, radar display,
   weapon panel, and outside terrain. Captures are retained in
   `work/qemu_out/screen_t49.png` and `screen_t55.png`.

The runtime test times out while the aircraft continues flying; this is an
expected non-clean exit because the game has no test-only `QUIT.COM` path once
Instant Action owns the screen.

## Memory conclusion

Instant Action reaches flight with `HIMEM.SYS` and `DOS=HIGH` and without
loading `EMM386.EXE`. This is consistent with the manual's statement that
Instant Action is independent of EMS settings. It does not yet establish the
EMS configuration needed by campaign or Red Flag paths; those remain a later
oracle experiment.
