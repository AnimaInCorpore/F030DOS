# sub_00058F9E — clipped shape draw through a pixel table

DOS identity: unpatched PANZER.EXE SHA-256
`115ada29636b32c3e07446fdf4569d97324d357a1e71dafb859dd95c3cb69a86`;
vaddr `0x58F9E..0x59476`, file `0xA1242..0xA171A`, established inventory ID.
Callee: `sub_00059476` (row copy with table lookup, own record). Status:
Verified for three connected Poland witnesses (terrain hexes of the map-view
renderer `sub_00010A64`, clipped on the left and top); the table's meaning,
other callers and connected game support remain open.

Same stack arguments as `sub_00058AB4`, `(clip, shape, index, x, y)`, caller
cleans; the same clip record, descriptor and shape layout. Every pixel written
is `table[pixel]`, the 256-byte table at object-2 offset `0x6E48`
(`mov al, [eax + 0x6e48]` twelve times in the body and its callee); this is the
only global it reads. Returns EAX = 0 in every witness.

Witnesses: `tests/fixtures/dos-shape.json`/`.bin` (`functionId` =
`sub_00058F9E`), captured by `work/probe_shape_contracts.py` from the
`axis_turn` checkpoint of `work/routes/poland.json`, with the table bytes at
entry (`tableHex`).

Implementations: **no hand-written port.** Native: `x86_sub_00058F9E` with shim
`sub_00058F9E` (a0 arena, a1 clip, a2 shape, d0 index, d1 x, d2 y; d0 result),
generated by `tools/x86x/translate.py` and checked by
`tools/check-native-shape.py`, which stages the table at `arena + 0x6E48`.
Differences: as for `sub_00058AB4`; the harness arena holds only the table, so
any other global read would see zero (the translation shows none).
