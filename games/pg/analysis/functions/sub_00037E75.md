## Contract and evidence

No arguments. Object-2 globals provide the SET name, resource prefix, layer
count/order, skip flags, cell widths, allocated destination pointers, geometry
styles and viewport row. `work/probe_loader_state.py` captures paired stream
reads, full entry/exit state and retained destination layers in the unchanged
DOS route `work/routes/poland.json`. Successful evidence:
`work/qemu_out/poland-fields-4/route.json` (CAPTURED, unchanged source disk).
File reads also pass `work/check_file_io.py` against pristine resources.

Read SET: discard one byte, five 20-byte fields, two LE uint16 inclusive maxima,
then discard `layerCount` LE words. Third string becomes the STM name. First,
second, fourth and fifth string fields are stack locals, not resource opens.
Use style CCB2 and maxima CC90-1/CC8E to call `sub_00010976`; clamp its stored
words to 640/426, center with signed arithmetic shift in 554/426, and call
`sub_00048105` with the bounds. Set active style to CCB3 afterwards.

For each configured layer, use BA94[21B9*15+index]. Skip if 21C0[layer] is
nonzero. Type CCA1[layer] 1 or 2 reads cells of that width into CBA0[layer*4],
also updating CB88 or CB8C respectively. Other types consume no bytes.
Open STM using prefix plus its name; read cells of two bytes to CB84 and close
it. The append source is CC2A, two bytes into the retained `..\\dat` name;
the initial SET append uses CC28. This asymmetry must be preserved. Close
STM before reading cells of two bytes from SET to 17934 and closing SET. Traverse columns
outside rows, clear bit 7 of each map word's high byte. Preserve EBX, ECX, EDX,
ESI, EDI, EBP and balance the stack; EAX is the final outer-loop counter
(18 for Poland), not the last addressed map word. Output pointer words stay
DOS virtual addresses.

Poland has 18×16 cells. SET positions: header 0..123; layer 0 (word) 123..699;
layer 2 (byte) 699..987; layer 4 (byte) 987..1275; layer 5 (byte) 1275..1563;
map words 1563..2139. STM 0..576. File names alone do not establish shape or
layer ordering. No source high bits are set in this resource; nonzero flags
remain a missing dynamic witness.

## Implementations and measured gate

JS `web/reference/loader.mjs`, native `src/common/loader.s`, same canonical ID.
`tests/fixtures/dos-loader.json` retains DOS inputs, globals, six arrays and
23 read contracts, plus 52 direct string helper cases. Node and browser match
the loader; Node and native match all 52 string returns/buffers. Native compares
6,779 canonical bytes in Falcon030 4 MB Hatari; common code assembles under
`-m68000`. Commands: `node tests/loader-reference.mjs` and
`python3 tools/check-native-loader.py --out build/loader-native-final` (fresh path).

Difference ledger: byte arena retains DOS LE globals and virtual pointers;
array pointers map by subtracting 0x1E0000 from their stored value. Native
GEMDOS adapter replaces DOS CRT binary streams and maps the measured DOS path
to the same pristine resource basename. Both logical adapters preserve read
ordering, sizes, counts and closure. Native handles need not equal DOS handles.
CRT allocation/buffering/error globals, dead local-stack bytes, CPU flags and
interrupt timing are outside this isolated game-output comparison. No claim
about the unported CRT bodies is made. Failed opens and short reads are
explicitly outside the measured success contract; the harness terminates on
them rather than supplying game state. Native maxima are restricted below
65535 and to allocations fitting the stated arena; the selected Poland
producer satisfies these bounds. The 2,228,224-byte sparse fixture arena is
a host-address representation, not a projected game memory budget.
