# sub_00058AB4 — clipped shape draw

DOS identity: unpatched PANZER.EXE SHA-256
`115ada29636b32c3e07446fdf4569d97324d357a1e71dafb859dd95c3cb69a86`;
vaddr `0x58AB4..0x58EB8`, file `0xA0D58..0xA115C`, established inventory ID.
Callee: `sub_00058EB8` (row copy, own record). Status: Verified for 29
connected Poland witnesses: border, panel and unit art drawn by the compositor
`sub_00014BF6`, and terrain hexes of the map-view renderer `sub_00010A64` at
x = -45 / y = -25, clipped on the left and top (20 witnesses touch a clip edge);
the shape pixel encoding itself, draws entirely outside the clip and connected
game support remain open.

Arguments on the stack: `(clip, shape, index, x, y)`, caller cleans (plain
`ret`). `clip` is a rectangle record `{descriptor*, x0, y0, x1, y1}`; the
descriptor is `{pixels*, maxX, maxY, ?, shadow*}` of the destination bitmap.
`shape` is a loaded `.SHP` image: 8-byte table entries from `+8`, entry
`[shape + 8 + 8*index]` is the sprite's offset, the next entry bounds it; the
sprite header carries bounds at `+8..+0x14` and data from `+0x18`
(`analysis/rendering.md`). Draws the sprite at `(x, y)` clipped to the record,
transparent pixels left alone; returns EAX = 0 in every witness. Reads no
globals (its translation has no arena access). Preserves EBX, ESI, EDI, EBP.

Witnesses: `tests/fixtures/dos-shape.json` and `dos-shape.bin` (probe
`work/probe_shape_contracts.py`, route `work/routes/poland.json`,
collector `tools/collect-shape-fixtures.py`): for each call the clip, the
descriptor dimensions, the shape bytes the call can reach, and the
destination region (the changed box widened by 16 pixels, clipped to the
bitmap) before and after, plus EAX. The shape image is captured as its header
and table through the next entry plus the sprite's own bytes, and rebuilt
sparsely in the harness. 29 witnesses of this function (a single-sprite shape
whose extent no next entry bounds is skipped); with `sub_00058F9E`'s three,
271,911 compared bytes.

Implementations: **no hand-written port.** Native: `x86_sub_00058AB4` with shim
`sub_00058AB4` (a1 clip, a2 shape, d0 index, d1 x, d2 y; d0 result), generated
by `tools/x86x/translate.py` (`analysis/x86-translation.md`) and checked by
`tools/check-native-shape.py` in Falcon030 Hatari: all witnesses equal.
JavaScript reference: none yet (the §4.3a reference for this function is open;
the DOS witnesses are the contract).

Differences: the harness builds the clip record and descriptor with native
pointers (DOS held virtual addresses: `dosPointers` in the fixture); the shape
image is used in place; the bitmap outside the compared region is not checked
(a write outside the clip would not be seen unless inside the 16-pixel margin).
Native flags, scratch registers and stack slots differ and are not read by the
caller. The first gate run found a wrong rule (`mov ah, al` read the register
after rotating it: 5 to 3,644 bytes differed per case); after the fix all
witnesses pass. Mutations on values the witnesses do not reach (the `adc`
chains that build the trivial-reject mask, all zero because no witness lies
entirely outside its clip; a captured `jle` whose equal case never occurs) are
not detected: see the translation document's evidence.
