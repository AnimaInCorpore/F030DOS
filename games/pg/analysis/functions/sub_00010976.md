## Contract and DOS evidence

No callees. EAX/EDX are pointers to output words. Unsigned byte at object-2
`0xCCB1` selects a 24-byte record starting at `0x21D6 + style*24`.
Unsigned LE words at `0xCC88` and `0xCC86` supply map maxima. The body computes:

```text
width32  = maxWidth  * (record[2]  + 1) + record[0]
height32 = maxHeight * (record[11] + 1) + record[7] + 1
```

It writes width's low word first, then height's low word, in little-endian
order. Aliased outputs therefore both end as the height word. Full height32
remains in EAX; EDX remains the height pointer. EBX, ECX, ESI, EDI and EBP are
preserved; stack balances. CPU flags and dead local-stack bytes are not a
portable contract. No game-state, file or hardware writes occur in this body.
Products fit unsigned 32 bits for all byte/word inputs; word stores wrap,
with no saturation or defensive clamp.

`tests/fixtures/dos-geometry.json` retains one connected route entry/exit and
six invocations of the unchanged DOS body, including maximal inputs, word
wrapping, odd output pointers and aliased outputs. Isolated fixtures mask
interrupts and temporarily inject only inputs; the probe restores changed
memory and CPU state before game flow resumes. They do not replace producers
in a supported connected port. Probe: `work/probe_geometry_contracts.py`.

Caller `sub_00037E75` invokes this at vaddr `0x38014`, then performs its own
clamps and centering. Those caller operations are not added to this function.
Style-table initialization and map loading remain connected-route dependencies.

## Implementations and differences

- JavaScript: `sub_00010976`, `web/reference/geometry.mjs`.
- m68k: `sub_00010976`, `src/common/geometry.s`; explicit ABI in source.
- m68k, generated: `x86_sub_00010976` with shim `sub_00010976` from
  `tools/x86x/translate.py` (`analysis/x86-translation.md`); passes the same 12
  geometry fixtures and the loader fixture (`--translated`, 2026-10-06).
- JS and m68k receive object-2 memory as a byte arena plus output locations;
  pointers are normalized to arena/output offsets. This is a representation
  and calling-convention change, validated against the same DOS fixtures.
- Native byte reads/writes preserve little-endian unaligned word behavior.
  Unsigned native word multiply produces the full 32-bit result. Native flags
  and scratch stack differ; neither is consumed by this caller's contract.
- File/display/input adapters: none inside this function.
