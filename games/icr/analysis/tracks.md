# Track archive processing — IndyCar Racing v1.05

Status: `RESOLVED` — all eight LZH archives test successfully and their 48
payload files are expanded with archive boundaries preserved under
`game/tracks/<track>`. The DOS runtime contract is the conventional
`C:\INDYCAR\TRACKS\<track>` layout; the builder now stages the tree there.
The repeated `ACE.STG`, `DEFAULT.ST1`, `EASY.STG` and `FAST.STG` files therefore
remain distinct per track and are never flattened into `game/installed`.

Reproduce this stage with:

```text
python tools/re/extract_media.py
python tools/re/extract_tracks.py
```

The machine-readable hash record is `work/track-manifest.json`.
